# 取列表的一段

## 功能描述

输入列表 + 起止下标（可带步长），输出**新列表**；起始含、结束不含，越界自动截断不报错。

## 推荐代码

```python
nums = [0, 1, 2, 3, 4, 5]

print(nums[1:4])     # [1, 2, 3]
print(nums[:3])      # [0, 1, 2]
print(nums[3:])      # [3, 4, 5]
print(nums[-2:])     # [4, 5]
print(nums[::2])     # [0, 2, 4]
print(nums[::-1])    # [5, 4, 3, 2, 1]  反转
print(nums[1:100])   # 越界不报错
```

## 语句解释

### list[起:止]

起始位置包含，结束位置**不包含**。所以 `[1:4]` 拿到下标 1、2、3。

### 省略某一端

`[:3]` 从头开始，`[3:]` 到结尾。负数从末尾数，`[-2:]` 是最后两个。

### [::步长]

第三个参数是步长。`2` 表示隔一个取一个，`-1` 表示倒着取。

## 原理解释

**一句话：** 它从起始位置走到结束位置之前，把沿途的元素挨个抄进一个新列表。

**执行逻辑：**

1. 把起止下标换成「实际起点」和「实际终点」（负数先换算成从末尾数的位置）
2. 从起点开始，按步长走
3. 每到一个位置，就把这个元素抄进结果列表
4. 走到终点（不含）就停
5. 返回新列表——原列表一个元素都没动

**机器层（可跳过）：** 一次线性遍历，结果占用与切片长度成正比。

**边界（从逻辑推出来）：**

- 第 1 步允许负数，所以 `[-2:]` 和 `[len-2:]` 等价
- 第 4 步「不含终点」是规则本身，所以 `[1:1]` 得到空列表
- 第 1 步把越界的下标夹到合法范围内，所以 `[1:100]` 不报错——**切片不会越界异常**
- 第 5 步抄的是**引用**，浅拷贝：元素本身还是原来那些对象，改可变元素会互相影响
- 反转变列表还有一种写法 `nums.reverse()`，但它原地改且返回 None

## 注意事项

- 结束位置不含，`[0:3]` 是前 3 个不是前 4 个。
- 切片是浅拷贝，嵌套列表里的子列表是共享的。
- `nums[::-1]` 生成新列表；`nums.reverse()` 原地反转返回 None。
- 切片赋值的长度可以不同：`nums[1:3] = [9]` 会删除一个元素。

## 使用场景

- 分页取数据（第 n 页 = `data[(n-1)*size : n*size]`）。
- 取首尾几条做预览。
- 复制一份列表（`nums[:]`）。
