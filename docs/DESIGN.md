# 视觉设计说明（冷纸工程手册）

> 2026-11-22 · 第二版设计 · 由肥鱼（鲸鱼娘）执笔，老大审定方向

## 为什么重做

朋友看完第一版说「一股 AI 味」。老大补了一句更准的：**"一切动画本质都是曲线，不能让曲线太平滑。"**

我把旧 QSS 扒下来数了一遍，确认这不是观感问题，是**可量化的模板痕迹**：

| 指标 | 旧版 | 问题 |
|---|---|---|
| 十六进制颜色 | **53** | 每个组件都在发明新颜色 → 视觉噪声 |
| 圆角档位 | **7**（5/7/9/10/12/14/16） | 没有体系，看着"顺手就加了" |
| 圆角盒子 | **12** | 卡片套卡片，每个元素都被关进描边盒 |
| 阴影/发光 | 紫色霓虹 + 青蓝次强调 | 深色底上的霓虹，AI slop 第一指纹 |
| 布局 | 居中 Hero + 胶囊示例 | "居中标题 + 三张卡 + CTA 色带"三件套 |
| 动效曲线 | `OutCubic` 一把通用 | 什么都是匀速减速，什么都"很顺" |

这六条恰好命中了行业里公认的 AI 生成痕迹清单。所以不是"换个配色"，是换一套做法。

## 新方向：冷纸工程手册

不装深空霓虹了，改成一页**技术手册的内页**：

- **一张纸的底**：近黑 `#0B0B0C`，不用渐变、不用光
- **暖白字**：`#E9E7E2`（不是冷白，长看不刺眼）
- **唯一的彩色是黄铜** `#C8A464`：只出现在三处——顶部一条 1px 线、最佳匹配的左侧竖线、主按钮
- **层级靠字号/字重/留白/细线**，不靠更多的框和颜色
- **拉丁标签一律等宽大写 + 字距**（`ENTRY ID / 条目 ID 怎么读`）：这是"工程感"的来源，也让中文和代码有明确的分工

### Token（改这里要同步 `theme.py` 与 `dark.qss`）

**颜色 15 个**（第一版我写成 12，实测 18，收口后是 15）

| 用途 | 值 |
|---|---|
| 底色 / 面板 / 悬停 | `#0B0B0C` / `#111113` / `#151517` |
| 细线 / 强调线 | `#26262A` / `#3C3C42` |
| 正文 / 次要 / 标签 | `#E9E7E2` / `#A6A29A` / `#6E6A64` |
| 黄铜 / 暗黄铜 | `#C8A464` / `#7E6A45` |
| 对 / 不对 | `#8FAE63` / `#B8634F` |
| 代码底 | `#0E0E10` |

**字号 8 档**：11（等宽标签）/ 12 / 13（正文）/ 15 / 19（条目标题）/ 20（搜索框）/ 24（详情标题）/ 32（首页主张）

**圆角 1 档**：`2px`。行、代码块、面板一律 0。

**字体 2 族**：`Microsoft YaHei UI`（中文与正文）+ `Cascadia Mono`（ID、标签、代码）

**没有**：阴影、渐变、发光、毛玻璃、装饰色块。

## 动效：三条有脾气的曲线

这是老大最在意的部分。旧版所有动画都吃 `OutCubic`——开头猛、结尾无痛滑入，正是"丝滑 = 假"的来源。

新版写了两条手写贝塞尔，各自有性格：

```
进入（前进）  cubic-bezier(0.16, 0.84, 0.24, 1.00)   150ms
返回（后退）  cubic-bezier(0.52, 0.00, 0.94, 0.30)   140ms
```

- **进入**：0.84 的前段回弹 → 立刻起步，末段收得干脆，不是"缓缓滑到终点"。
- **返回**：前 20% 几乎不动（`valueForProgress(0.2) < 0.15`），最后"啪"地抽走。读起来像**关掉一页纸**，而不是画面慢慢溶化。
- **淡出比位移早结束**（0.85 倍时长）：眼睛先看到"移动"，后看到"消失"，顺序对了才不像 PPT 转场。
- 位移只有屏宽的 **10%**：够表达方向，不表演。

测试 `tests/test_keyboard.py::test_过渡曲线不是匀速` 会在曲线退化成线性时报警——曲线也是有验收标准的。

## 布局：从"居中三件套"改成编辑式排版

| 屏 | 旧 | 新 |
|---|---|---|
| 首页 | 居中大搜索框 + 胶囊示例 + 星点背景 | 左对齐：品牌行 → 主张（32px）→ 全宽搜索框 → 刻度线 + 键位提示 → **左"试这些（编号列表）" / 右"条目 ID 怎么读（表格）"** |
| 结果 | 圆角卡片 + 分数 + 彩虹徽章 | 最佳匹配＝带黄铜左线的区块；其余＝编号 + 细线分隔的行；层级＝等宽小字（BUILTIN / STDLIB / 3RD-PARTY） |
| 详情 | 一堆圆角盒子 | 标题 24px → 等宽元信息行 → IMPORT 面板（左细线）→ SIGNATURE → 每节一条细线 + 等宽小标签 |

## 结果（同一把尺子量）

| 指标 | 旧版 | 新版 |
|---|---|---|
| 颜色数 | 53 | **15**（收口前是 18：把三个“发明出来的”并回主色） |
| 圆角档位 | 7 | **2**（0 和 2px） |
| 圆角盒子 | 12 | 13 个选择器用到 `border-radius`，但值只有 0/2 |
| 阴影 / 渐变 / 发光 | 0 阴影但用霓虹色 | **0**，且强调色只有 1 个 |
| 动效曲线 | 1 条通用 OutCubic | **2 条手写贝塞尔，方向相反的性格** |
| 有测试守着 | 无 | 曲线退化、过渡残影、时长区间共 3 条 |

量法：`py -3 tools/audit_tokens.py`（数颜色/字号/圆角/阴影）。

## 自查后补的修正（同一天第二遍）

第一版改完我自己过了一遍，发现七处粗糙，都修了：

| 问题 | 修法 |
|---|---|
| 首页挂着 3D 暗紫发光图标，和冷纸手册两套语言 | 换成代码画的**扁平黄铜四角星**（1px 线，跟全站同一套语法）；PNG 只留给窗口/任务栏 |
| 等宽标签里的中文被 letter-spacing 撑成「其 他 相 关」 | 字距从 1.4px 降到 0.5px，中文不再靠字距做"工程感" |
| 标签色 `#6E6A64` 对比度约 3.5:1，11px 读不清 | 提到 `#8B857C`（≈4.6:1，过 AA） |
| 最近搜索没有编号，左边缘节奏断掉 | 给它 30px 左内边距，和 01–04 的编号列对齐 |
| 详情页「执行逻辑」1–4 行挤成一段 | 编号行加 7px 行距 |
| IMPORT 面板（最关键的信息）用最弱的灰线 | 换成暗黄铜 `#7E6A45` |
| 首页中下部 250px 空白像没排完 | 底部加一条流程行「问一句 → 看候选 → 读原理 → 抄代码」 |
| 窗口变小时结果列表会被裁掉 | 候选列表放进滚动区 |
| DESIGN.md 写 12 色、实测 18 色 | 收口到 15 色，文档改成实测值 |
